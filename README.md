# 💰 Finora – Personal Expense Tracker

> Your money, clearly organized.

Finora is a full-stack personal expense tracking web application built with Java, Spring Boot, MySQL, REST APIs, HTML, CSS, and Vanilla JavaScript.

It allows users to manage daily expenses, organize transactions by category, search and filter records, and view spending summaries through a clean and responsive dashboard.

---

## ✨ Features

- 📊 Interactive spending dashboard
- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🗑️ Delete expenses with confirmation
- 🔍 Search and filter transactions
- 🏷️ Category-based expense tracking
- 💳 Payment method tracking
- 📈 Spending summaries and analytics
- 🔔 Toast notifications
- 📱 Responsive design
- 💰 Indian Rupee (₹) currency support
